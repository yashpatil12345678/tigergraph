# Submission checklist

- [ ] Enable public GitHub repository visibility.
- [ ] Supply `data/transactions.csv`, `data/identity.csv`, and `data/closed_cases_history.csv` (or set `INVESTIGATION_DATA_DIR`).
- [ ] Configure server-only `TIGERGRAPH_HOST`, `TIGERGRAPH_GRAPH_NAME`/`TIGERGRAPH_GRAPH`, and the required token or credentials.
- [ ] Run `pnpm build`, `pnpm test`, `pnpm benchmark`, and `pnpm validate`.
- [ ] Confirm the deployed demo URL and TigerGraph authenticated health status.
- [ ] Complete the official submission form, technical blog, and social posts.
